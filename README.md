# 오늘의 9회

배포 주소: https://hankkidaily-vibe-coding.vercel.app

아마야구 선수가 매일 훈련과 마음을 함께 기록하는 성장 일지입니다. 단순한 훈련량 체크를 넘어 몸의 에너지, 감정, 루틴, 새롭게 알게 된 나, 스스로에게 건네는 말을 기록할 수 있습니다.

## 주요 기능

- 오늘의 에너지와 감정 체크인
- 수분, 스트레칭, 이미지 트레이닝, 쿨다운 루틴 기록
- 훈련 내용과 자기 성찰 작성
- 기기 안에 자동으로 보관되는 일별 기록
- 연속 기록일, 주간 발자국, 성장 통계
- 매일 바뀌는 응원 문장
- 모바일과 데스크톱 반응형 화면

## 시작하기

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

완성본 확인:

```bash
npm run build
```

## 기록 보관 방식

현재 버전의 기록은 브라우저의 `localStorage`에 저장됩니다. 로그인 없이 바로 사용할 수 있고, 같은 브라우저와 기기에서 기록이 유지됩니다. 브라우저 데이터를 삭제하거나 다른 기기에서 접속하면 기록이 이어지지 않습니다.
