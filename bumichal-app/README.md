# 부미챌 앱

부미챌을 실제 서비스 앱으로 개발하는 프로젝트입니다.

## 목표
- 회원용 모바일 웹앱(PWA)
- 오늘 / 우리 / 수면 / 기록 / MY
- 시간대별 부미챌 문장
- 마음쉼터 AI 상담
- 운영자 전용 카카오톡 대화/이미지 가져오기
- Google Sheets 기반 수면 데이터는 브라우저 직접 접근이 아니라 서버 API를 통해 연동
- Vercel production 배포

## 운영 원칙
- 회원에게 추가 입력 부담을 최소화
- 관리자 기능은 일반 회원에게 숨김
- 상담 기록은 기본 비공개
- 기수 표시는 데이터로 관리하고 브랜드 로고에는 고정하지 않음
